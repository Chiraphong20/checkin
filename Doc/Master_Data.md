# ข้อมูลหลัก (Master Data)

เอกสารนี้รวบรวมข้อมูลอ้างอิงและค่าคงที่ระดับระบบที่ถูกใช้งาน (Lookup Data) เช่น Dropdown, สิทธิ์พนักงาน เป็นต้น

---

## 1. สิทธิ์การใช้งานระบบ (`User Roles`)

**ใช้ในส่วน:** ระบบ Login, การแสดงเมนู และการจำกัดสิทธิ์ API
**Field:** `users.role`

| ค่าในระบบ (Value) | ชื่อหน้าที่ | สิทธิ์การทำงานชองระบบ |
| :--- | :--- | :--- |
| `EMPLOYEE` | พนักงาน | ดูเวลาทำงานตัวเอง กด Check-in/Check-out |
| `ADMIN` | ผู้ดูแลระบบ | จัดการบัญชีทุกคน อัปเดตข้อมูล ทำแมนนวลการลงเวลา ออกรายงาน |

---

## 2. สถานะการลงเวลา (`Check-In Status`)

**ใช้ในส่วน:** ตารางหรือรายงานการทำงาน (Dashboard)
**Field:** `check_ins.status`

| ค่าในระบบ (Value) | สีบน UI | ความหมาย |
| :--- | :--- | :--- |
| `ON_TIME` | 🟢 เขียว | ลงเวลาเข้างานตรงเวลา (ตามเกณฑ์ของบริษัท) |
| `LATE` | 🟡 เหลือง | ลงเวลาสายเกินเวลาที่กำหนด |
| `ABSENT` | 🔴 แดง | ขาดงาน หรือลืมลงเวลา (รอแจ้งแก้ไขโดย Admin) |

---
