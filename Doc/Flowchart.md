# แผนผังการทำงาน (Flowchart)

เอกสารแสดงลำดับขั้นตอนการทำงาน (Workflow) หลักในระบบผ่านผังงาน (Flowchart)

---

## 1. Flowchart ระบบลงเวลา (Check-in / Check-out)

แสดงขั้นตอนตั้งแต่พนักงานทำการล็อกอิน จนไปถึงการประทับเวลา

```mermaid
flowchart TD
    A([เริ่มต้น]) --> B{เข้าสู่ระบบ?}
    B -- ไม่สำเร็จ --> C[แสดงแจ้งเตือนรหัสผิด]
    C --> B
    B -- สำเร็จ --> D[หน้า Dashboard พนักงาน]
    D --> E{ตรวจสอบสถานะวันนี้}
    
    E -- ยังไม่ Check-in --> F[แสดงปุ่ม Check-in]
    F --> G[พนักงานกดเข้างาน]
    G --> H[ระบบบันทึกเวลาปัจจุบัน]
    H --> I[เปลี่ยนไอคอนเป็น เข้างานแล้ว]
    
    E -- Check-in แล้ว --> J[แสดงปุ่ม Check-out]
    J --> K[พนักงานกดเลิกงาน]
    K --> L[ระบบบันทึกเวลาเลิกงาน]
    L --> M[สรุปชั่วโมงทำงานรายวัน]
    
    I --> N([สิ้นสุด])
    M --> N([สิ้นสุด])
```

---

## 2. Flowchart การจัดการรายงาน (Admin Payroll Flow)

แสดงขั้นตอนฝั่งหัวหน้างาน/HR ในการออกรายงานสรุปเงินเดือน

```mermaid
flowchart TD
    A([เริ่มต้น Admin Login]) --> B[เข้าสู่เมนู Payroll Report]
    B --> C[เลือก เดือน/ปี ที่ต้องการ]
    C --> D[กด Generate Report]
    D --> E[ระบบดึงตาราง Check-in ของทุกคนในเดือนนั้น]
    E --> F[หักวันมาสาย / วันลืมลงเวลา]
    F --> G[รวมชั่วโมงทำงาน x ฐานเงินเดือน]
    G --> H[แสดงผลลงตารางรายงาน]
    H --> I{ต้องการ Export?}
    
    I -- ใช่ (PDF) --> J[สร้างไฟล์ Document ให้ดาวน์โหลด]
    I -- ใช่ (Excel) --> K[สร้าง Spreadsheet ไฟล์ .xlsx]
    I -- ไม่ --> L([สิ้นสุด])
    
    J --> L
    K --> L
```
