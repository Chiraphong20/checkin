# คู่มือผู้ใช้งาน (User Manual)

เอกสารฉบับนี้อธิบายวิธีการใช้งานระบบ Check-in & Payroll แบบทีละขั้นตอน สำหรับบุคคลทั่วไปและผู้ดูแลระบบ

---

## ส่วนที่ 1: สำหรับพนักงาน (Employee)

### 1.1 การเข้าสู่ระบบ
1. เปิดเว็บเบราว์เซอร์แล้วไปที่ URL ของระบบ (เช่น `http://checkin.company.com`)
2. กรอก **Username** และ **Password** ที่ได้รับจากฝ่ายบุคคล
3. กดปุ่ม `ล็อกอิน (Login)`

### 1.2 การประทับเวลาเข้างาน (Check-In)
1. เมื่อเข้าสู่ระบบ จะพบกับระบบตรวจจับเวลาแบบ Real-time บน **หน้าแรก (Dashboard)**
2. หากยังไม่กดเข้างาน ปุ่มสีเขียวตัวใหญ่จะแสดงคำว่า **"ลงเวลาเข้างาน (Check-in)"**
3. กดที่ปุ่ม ระบบจะดึงเวลา Server ทันที
4. ถ้าระบบขึ้นว่าบันทึกสำเร็จ เป็นอันเสร็จสิ้น และเวลาจะโชว์ว่าท่านมา "ตรงเวลา" หรือ "สาย"

### 1.3 การประทับเวลาออกงาน (Check-Out)
1. เมื่อถึงเวลาเลิกฮาน ปุ่มในหน้า Dashboard จะเปลี่ยนสถานะเป็น **"ลงเวลาเลิกงาน (Check-out)"** สีส้ม/แดง
2. กดปุ่มเพื่อบันทึกการออกงาน (ระบบไม่อนุญาตให้กดซ้ำอีกในวันนั้น)

### 1.4 เช็คประวัติการลงเวลา
1. คลิกที่เมนูบาร์ด้านข้าง **"บันทึกเวลาของฉัน (My History)"**
2. เลือกดูประวัติย้อนหลังเป็นรายเดือน หรือรายสัปดาห์ได้ว่า ใน 1 เดือนมาสายกี่ครั้ง

## ส่วนที่ 2: สำหรับฝ่ายบุคคล (Admin / HR)

### 2.1 หน้า Dashboard ผู้บริหาร (Admin Dashboard)
1. เมื่อล็อกอินด้วยบัญชี HR จะเห็นสถิติภาพรวม เช่น **พนักงานเข้างานวันนี้กี่คน ขาดกี่คน สายกี่คน** 
2. จะมีตารางแสดงเวลาเข้างานของแผนกต่างๆ เพื่อการมอนิเตอร์

### 2.2 การลงเวลาแทนพนักงาน (Manual Adjust)
ในกรณีพนักงานลืมนำโทรศัพท์มา หรือระบบกดไม่ได้:
1. ไปที่เมนู **"จัดการเวลาพนักงาน (Manage Check-ins)"**
2. เลือกวันที่และชื่อพนักงาน
3. กดปุ่มไอคอน **[ดินสอ/แก้ไข]**
4. ระบุ "เวลาเข้างานใหม่" และ ต้องบังคับใส่ "หมายเหตุ (Note)" ทุกครั้ง เช่น *พนักงานลืมมือถือ* เพื่อเป็นหลักฐานต่อนักบัญชี
5. กด **Save**

### 2.3 การออกรายงานเงินเดือน (Payroll Report)
1. เข้าไปที่เมนู **"ออกรายงาน (Payroll)"**
2. เลือก เดือน และ ปี (เช่น เดือน สิงหาคม 2026)
3. ระบบจะทำงานและแสดงตารางเงินสุทธิของพนักงานทุกคน
4. สามารถกดปุ่ม **"Export as Excel"** ด้านมุมขวาบน เพื่อนำไฟล์เข้าโปรแกรมบัญชีส่งจ่ายเงินได้ทันที
